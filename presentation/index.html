Current limitations

A working prototype.
Not one-click setup yet.

Deployment

Too much setup.

Zoom SDK, provider credentials, CLI login and platform permissions.

Conversation

Judgment is imperfect.

Routing, turn boundaries and echo can fail. Response latency varies.

Reliability & scope

A narrow primary path.

macOS Zoom, English speech. Limited recovery after input failures.

Task context

Updates must be explicit.

A worker starts with a snapshot. Later decisions need a follow-up.
