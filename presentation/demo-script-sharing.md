# 共享彩排讲稿

共享服务只提供讲稿页面与编辑同步，沿用三列、个人视图和直接编辑。每个人的角色选择、滚动和计时独立。

在仓库根目录运行：

```bash
node frontend/demo-script-server.mjs
```

默认监听 `127.0.0.1:5193`，打印带随机访问路径的本地链接。另开一个终端：

```bash
cloudflared tunnel --url http://127.0.0.1:5193 --no-autoupdate
```

将输出的 `https://….trycloudflare.com` 与本地链接的完整 `/s/…/` 路径拼接，保留末尾 `/`，转发给队友。持有完整链接的人可以查看和编辑。本机休眠、服务或隧道停止会导致无法访问，重启临时隧道通常会换域名。

- 修改在服务端写入成功后才广播并显示「已同步」。状态默认保存在 `.runtime/demo-script-shared.json`，包含访问路径和逐字段版本，服务重启后保留。
- 编辑按台词字段独立同步。同一句有并发修改时保留本地版本，显示双方文本，由编辑者选择共享版本或自己的版本。
- 断线期间的待同步编辑缓存在当前浏览器；恢复后检查版本，有冲突时不会自动覆盖。未同步时离开页面会提示，浏览器不能保存草稿时页面也会提示。
- 共享版不会自动上传其他本地讲稿的旧草稿。首次启动可用 `SPARKIE_SCRIPT_SEED=/path/to/edits.json` 导入已确认的字段修改；已有服务端状态优先。
- 下载的 HTML 包含当前页面的修改，是独立副本，后续编辑不再同步。需要继续协作时使用共享链接。
- 每个字段限制 20,000 字。页面不提供账号体系、逐字符合并或版本历史。

可通过 `SPARKIE_SCRIPT_PORT`、`SPARKIE_SCRIPT_STATE` 调整端口和保存路径；测试使用独立状态文件。服务没有目录浏览或会议/任务 API 路由。

验证命令：

```bash
node --test frontend/demo-script-server.test.mjs
npm --prefix frontend run build
```

服务测试覆盖双客户端广播、同字段冲突、不同字段并行修改、保存后重启恢复、文本安全嵌入和未授权路径。浏览器验收覆盖真实输入同步、角色视图独立、冲突选择、断线恢复及独立文件导出；这些检查不涉及 Zoom 或模型能力。
